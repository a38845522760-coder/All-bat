# Phase 1 — Completion Checklist

## Included in this package

- [x] Godot 4 project configuration.
- [x] Mobile renderer selected as the initial rendering path.
- [x] Boot scene and entry script.
- [x] EventBus autoload.
- [x] AppState autoload.
- [x] SettingsManager with persistent, validated settings and four declarative quality profiles.
- [x] SaveManager with a versioned JSON save container.
- [x] Module-oriented folder layout.
- [x] Architecture, roadmap, and development documentation.
- [x] Git ignore rules for generated data, exports, and signing material.

## Not yet verified

- [ ] Open/import in Godot Editor.
- [ ] Run the project in Godot and check the debugger output.
- [ ] Export and install an Android test build.
- [ ] Test the Mobile renderer on the actual target device(s).

## Explicitly not part of Phase 1

- No playable character or first-person controller.
- No industrial map or imported 3D assets.
- No weapons, combat, or AI implementation.
- No completed game modes or shop.
- No networking implementation yet.
- No zombie story or zombie-mode implementation.
- No APK or release signing configuration.

Do not mark Phase 1 as fully verified until the unchecked editor/device tests have been completed.
